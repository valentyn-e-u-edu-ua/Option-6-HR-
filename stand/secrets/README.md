# Секрети стенда

Створіть тут два файли (інструкція — у ../README.md, крок 1):

- `pg_superuser_password.txt` — пароль суперкористувача `postgres`
- `backup_passphrase.txt` — парольна фраза для шифрування бекапів (етап 6)

Файли передаються в контейнер як docker secrets (`/run/secrets/...`), а не як змінні середовища: змінні середовища видно в `docker inspect`, у `/proc/<pid>/environ` і в журналах CI.

**Не комітьте ці файли в git і не вставляйте їх у звіт.**
